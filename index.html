Frequently asked questions

Yes, that is a normal way to start. Describe what is slow, repetitive or hard to see in your current process, and I will suggest what would help. You do not need to know the technology.

How do you scope a project?

I ask for a description of the problem, a sample file or screenshot, and who will use the result. I then confirm deliverables, timeline and price in writing before starting.

What data access do you need?

A sample export is usually enough to start. If the work needs a live connection, I need read access to the sources involved. Where possible I work from anonymised files.

How is the work delivered?

In stages. I share progress along the way, test against your data, and deliver the finished Power BI report, Excel files, flows or app.

What do I get at handover?

The working solution, short written notes and a walkthrough, so your team can use and maintain it.

Do you use AI tools?

Yes, as support for routine parts of the work. I do not build AI models or AI agents. What you are paying for is understanding your requirements, designing the right solution, connecting the tools and checking that the result is accurate and works reliably.

How do you handle confidential data?

I use only the data the task needs and keep it out of public places. If you ask, I will sign an NDA before you share anything.

Rule-Based Excel Automation

One automated workflow that picks the right clean-up for each uploaded Excel file, based on its name.

Power AutomateExcelSharePointOutlook

Project Overview

Uploaded Excel files come in several types. The flow reads the file name, decides which of 13 predefined transformations applies, runs it, files the output in SharePoint and emails the user a link or the file itself.

Business Challenge

Each file type needed its own transformation. The results also had to be stored in an organised way and reach the people waiting for them.

My Contribution

I built the flow from start to finish: the file-name detection, the Excel standardisation behind each transformation, the SharePoint folder structure and the email notifications.

Solution

  • Define the 13 transformations and the file-name pattern that selects each one.
  • Detect the file type from the name when a file is uploaded.
  • Run the selected transformation to standardise the Excel data.
  • Save the processed file in a structured SharePoint folder.
  • Send an email with a link to the output, or the file attached.

How It Works

  1. Upload

    A file is uploaded to the watched location.

  2. Detect

    The flow reads the file name and identifies the file type.

  3. Transform

    The matching one of the 13 transformations is applied.

  4. Deliver

    The output is saved in SharePoint and the user gets an email.

Technologies Used

Power AutomateExcelSharePointOutlook email

Results

Uploaded files go through the transformation for their type and arrive in SharePoint with a notification. I have not published time-saving figures for this flow.

KNIME Data Reconciliation & Excel Automation

An automated check that compares Power BI figures with source data from a web portal and lists every mismatch.

KNIMEPower BIExcel

Project Overview

Source data was downloaded from a web portal and compared with figures from automatically refreshed Power BI reports. The files held millions of records. I built a KNIME workflow that applies predefined rules over several processing steps, compares the two sides and reports every difference.

Business Challenge

Power BI figures had to be confirmed against the portal data. The files were large and the comparison depended on many rules, which made a figure-by-figure check by hand slow and easy to get wrong.

Previous Process

The comparison was done by hand. Source data was downloaded from the portal and compared with the Power BI data to check accuracy and find mismatches.

My Contribution

As the data analyst, I carried out the validation across multiple files with millions of records and built the KNIME workflow that automated it, including its rule-based logic and processing steps.

Solution

  • Download the source data from the web portal and collect the matching Power BI report data.
  • Validate figures across multiple files with millions of records to confirm the report matches the source.
  • Break the comparison into processing steps in KNIME, with predefined rules controlling how the data is handled at each step.
  • Compare the figures from both sides and flag differences.
  • Output a list of mismatches for follow-up.

How It Works

  1. Load

    Source files and Power BI report data are read into the workflow.

  2. Apply rules

    Predefined rules process the data through a sequence of steps.

  3. Compare

    Figures from the two sides are matched against each other.

  4. Report

    Mismatches are listed so they can be investigated.

Technologies Used

KNIMEPower BIExcelWeb portal exports

Results

The workflow runs the comparison and lists the mismatches, so the figure-by-figure check no longer has to be done by hand. I have not published measured time savings for it.
